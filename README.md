# Проект: Тестирование калькулятора

## Описание

Данный проект содержит автоматизированный тест для проверки работы калькулятора, расположенного по адресу: https://bonigarcia.dev/selenium-webdriver-java/slow-calculator.html

Тест написан с использованием:

* **Python**
* **Pytest**
* **Selenium WebDriver**
* **Allure Reports**

Структура файлов:

* `calculator_page.py` — Page Object Model (POM) для страницы калькулятора.
* `calculator_test.py` — тест, использующий Allure для формирования отчёта.

## Как запустить тесты и сформировать отчёт

### 1. Установить зависимости

Убедиться, что установлен Python 3.8+ и выполнить установку зависимостей:

pip install -r requirements.txt

(Если файла `requirements.txt` нет — добавить необходимые библиотеки вручную.)

Основные зависимости:

pytest
selenium
allure-pytest

### 2. Запуск тестов с генерацией Allure-результатов

Для формирования отчёта необходимо запустить тесты с указанием директории для хранения результатов:

pytest --alluredir=allure-results

После выполнения появится папка `allure-results/` со всеми данными для построения отчёта.

## Как просмотреть сформированный отчёт

### Способ 1: Локальный просмотр через Allure CLI

1. Установить Allure Commandline.

2. Сформировать и открыть отчет:

allure serve allure-results

Команда автоматически запустит веб‑сервер и откроет отчёт в браузере.

## Примечания

* Отчёт Allure отображает шаги теста, вложенные действия, статусы, вложения и подробную информацию.
* Тест требует установленного браузера Google Chrome и chromedriver, соответствующего версии браузера.


# Полный тест оформления заказа на SauceDemo

Этот тест автоматизирует полный пользовательский сценарий:

- авторизация;

- добавление товаров в корзину;

- переход к оформлению заказа;

- ввод данных покупателя;

- проверка итоговой суммы.
